# Support

graft is a volunteer spec. There is no SLA.

| Kind | Where |
| --- | --- |
| "is this the intended dirty set?" | GitHub issue, label `question` |
| schema change | RFC issue (`.github/ISSUE_TEMPLATE/rfc.yml`) |
| bug in `ref/` or examples | GitHub issue, template `bug` |
| vulnerability | [SECURITY.md](SECURITY.md) |
| conduct | [SECURITY.md](SECURITY.md), marked `conduct` |

Read [docs/mission.md](docs/mission.md) and [docs/principles.md](docs/principles.md)
before asking whether graft should version mp4s with git. It should not.

Do not expect maintainers to reverse-engineer a CapCut draft or to bid on
editing work.
