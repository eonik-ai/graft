# Brand

Two clips. One join.

The left frame is the new take (the hook). The right frame is the body
that stays. The chevron is the **graft** — the only place the compiler
rewrites. It reads as a splice, a playhead, and a scion all at once.

The word is **graft**, lowercase, like `git`. It is not set inside the
mark. The PNG lockup is the canonical drawing. `mark.svg` is the same
geometry for scale.

## Colour

| Role | Approx. | Meaning |
| --- | --- | --- |
| Field | `#000000` | The compile happens in the dark |
| Frames | `#3D4458` | Slots. Identical wood, different takes |
| Join | `#9BB0FF` → `#3ED89A` | The kerf. The only new bytes |
| Word | `#FFFFFF` | lowercase `graft` |

## Do not

- Recolour the chevron to a flat brand-primary. The gradient is the join.
- Drop the sprockets. They are why this is video, not a generic arrow.
- Put the new take on the right. Time reads left to right.
- Add a tree, a camera, or a play triangle. The frames and the graft
  are enough.
- Set a second wordmark under the PNG lockup.
