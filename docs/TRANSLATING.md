# Translating the README

English [`README.md`](../README.md) is the only README.

Locale siblings were removed. They lagged the product and read as
template theatre on a compiler with no external hosts. Schema, ADRs,
and `docs/` stay English. Do not add `docs/<locale>/`.

Do not add `README.<locale>.md` until a host other than this CLI is
shipping and someone asked for that language. A language bar is not a
substitute for a host.
