# Walkthrough

The README example is a real compile: [example-hook.png](assets/example-hook.png)
and [example-body.png](assets/example-body.png). Hook changes; body is a
cache hit.

Rebuild from local takes (essence stays out of git):

```sh
HOOK= BODY= CTA= HOOK2= make readme-example
```

`make walkthrough` is the color-plate fallback when you have no footage.
Do not use it as the public demo.
